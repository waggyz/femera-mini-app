# Low-level material response kernels

This folder contains both reference and optimized material response functions, for real and hypercomplex algebras.

**Linear**

- **Thermal**: isotropic, anisotropic
- **Elastic**: isotropic, cubic, orthotropic, anisotropic
- **Thermal-elastic**: one- and two-way coupling

**Nonlinear**

- **Thermal**: cubic spline
- **Kinematic plasticity**: linear, cubic spline hardening
